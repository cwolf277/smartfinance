# SmartFinance Frontend

React dashboard for SmartFinance.

## Scripts

- `npm start` — dev server on http://localhost:3000
- `npm run build` — production build to `build/`
- `npm test` — Jest test runner
- `npm run lint` — ESLint

## Environment

Set `REACT_APP_API_URL` to override the backend URL (default `http://localhost:5000`).
